# EXPANDE+ — Assets

Elementos separados del brand sheet proporcionado, recortados individualmente y exportados como PNG con fondo transparente.

## Archivos

- `logo-wordmark-expande-plus.png` — logotipo horizontal / wordmark principal.
- `logo-symbol-expande-plus.png` — isotipo circular E+.
- `brand-banner-expande-plus.png` — banner horizontal de marca.
- `app-icon-light.png` — icono claro.
- `app-icon-dark.png` — icono oscuro.
- `service-social-media.png` — marketing / redes sociales.
- `service-analytics.png` — analítica / métricas.
- `service-web-search.png` — web / buscador.
- `service-responsive-design.png` — páginas y apps responsive.
- `service-ai-chatbot.png` — IA / chatbot.
- `service-security.png` — seguridad / infraestructura.

## Uso sugerido en Next.js

Coloca la carpeta `assets` dentro de `public/expande-plus/`.

Ejemplo:
`/public/expande-plus/logo-symbol-expande-plus.png`

Después puedes usar:
`<Image src="/expande-plus/logo-symbol-expande-plus.png" ... />`

Todos los archivos conservan transparencia PNG y nombres semánticos para que Codex pueda identificarlos fácilmente.
